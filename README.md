# Galapagos drug perturbation project

This repository hosts the code, notebooks, and conda environments used for the analysis.

## Structure

* `01_data`: Metadata and supplementary files
* `02_figures`: Figures for manuscript
* `03_preprocessing`: Scripts for QC, doublet removal, ambient RNA correction, etc.
* `04_annotation`: Scripts for cell type annotation
* `05_figure_overview`: Scripts to generate overview figures
* `06_figure_granulocytes`: Scripts for Granulocyte analysis and figures
* `07_figure_target_expression`: Scripts to compare drug target expression across disease models
* `*.yml files`: Conda environments used for the respective analyses

## Data 

Raw data will be deposited at the public GEO data repository upon publication. Processed data will be uploaded to Zenodo.
