## Disease severity-resolved single-cell atlas of murine bleomycin-induced lung fibrosis

This repository hosts code, notebooks, and conda environments used for the analysis.

## Structure

* `01_data`: Metadata and supplementary files
* `02_figures`: Figures for manuscript
* `03_preprocessing`: Scripts for QC, doublet removal, ambient RNA correction, etc.
* `04_annotation`: Scripts for cell type annotation
* `05_figure_overview`: Scripts to generate overview figures
* `06_figure_granulocytes`: Scripts for granulocyte analysis and figures
* `07_figure_target_expression`: Scripts to compare drug target expression across disease models
* `08_figure_perturbation_analysis`: Scripts to analyse effects of pharmacological pertubations
* `09_spatial_analysis`: Scripts to analyse publicly available 10X Visium data
* `10_ccc_analysis`: Scripts to run cell-cell communication analysis
* `*.yml files`: Conda environments for the respective analyses

## Data 

Raw data will be deposited at the public GEO data repository upon publication. Processed data will be uploaded to Zenodo.

Publicly available data analysed in this study can be accessed as described below:

1OX Visium data of murine bleomycin-induced lung fibrosis generated by [Franzén & Olsson Lindvall et al. *Nature Genetics* (2024)](https://doi.org/10.1038/s41588-024-01819-2) are available at the EBI ArrayExpress collection of the BioStudies database under accession number [S-BSST1409](https://www.ebi.ac.uk/biostudies/studies/S-BSST1409).
scRNA-seq data of the integrated human lung cell atlas generated by [Sikkema et al. *Nature Medicine* (2023)](https://doi.org/10.1038/s41591-023-02327-2) can be found on [Zenodo](https://doi.org/10.5281/zenodo.7599104).
scRNA-seq data of the ex vivo model of human lung fibrogenesis (PCLS treated with Fibrotic Cocktail) generated by [Lang, Gote-Schniering et al. *Science Translational Medicine* (2023)](https://doi.org/10.1126/scitranslmed.adh0908) can be found on [Zenodo](https://doi.org/10.5281/zenodo.7537493).
